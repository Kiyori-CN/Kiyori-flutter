## 提供方包与脚本

core/extensions复用AppStore/ResourceRef；schema19保存TOOLPKG包和安装恢复账本，
目录键为TOOLPKG:package_id:provider_id并绑定revision。启停/升级/卸载先撤销新调用、
取消等待旧worker释放包租约；卸载墓碑使重装不接受旧请求。JS入口每次验证hash。
提供方包支持schema1/2 JSON/HJSON清单与单JS源，schema2的distribution仅是构建元数据；
缺字段沿旧默认值，清单选择/相对入口共用有界解析。受控HTTP与正式ChatRun复用同client/Registry/Gate，
JS只接凭据引用，限定GET目录/POST生成，取消等待VM/HTTP释放，终态核对全文和用量。
密钥池调用testConnection，综合探测调用sendMessage；发送前calculateInputTokens投影
最终history窗口，和发送共享一个模型配额，不将窗口计数当实际Usage。
扩展自动总结在计数后判断阈值；未触发不轮换总结凭据或创建用量记录。触发先释放
聊天许可，短事务复核冻结身份后取得总结凭据；生成后按新history重新计数并检查上限。
动态provider来自同Runtime，撤销不替换配置引用；AI抽屉扩展页的插件导入、详情、启停和
确认卸载已接同owner，成功后刷新模型目录。文件选择复用模型分片句柄，原包详情按revision
在blocking worker核验hash，撤销及Runtime关闭等待读取释放。详情/删除确认绑定原revision，
变更关闭旧模态；其它扩展标签和未接动作只保留原外观。包完整格式兼容与排序继续实施。
ZIP支持32/64位data descriptor，完整局部/中央布局与CRC核验不能遗漏隐藏重复条目。
依赖、环境、子包及其他旧宿主能力继续实施，详见ADR0012与status。

core/scripts拥有脚本期限、4并发槽、8事件背压和取消树；platform/scripts持有单次
QuickJS-NG runtime/context，FFI装配，核心不依赖具体引擎。CommonJS注册及调用分别
返回有界JSON，异常不回显源码/输入，超时/取消终态等待实例析构。默认无文件、网络、
进程或模块访问；执行限制不是OS安全沙箱。包安装与网络授权接线状态以status为准。

## 产品壳与一级导航

UI 以旧 Kiyori Android 为保真基线；跨平台重构调整代码与目录，不改变已经确定的产品设计。首页为负一屏 / 首页 / AI 对话三页横向布局，首页底栏仅五个图标，无文字标签。未接入动作不创建业务副作用，具体尺寸与状态见 [UI 复刻契约](../design/ui-parity.md)。

`HomeShell` 唯一持有一级目的地与浏览器返回来源。四个一级页面属于 Dart UI 投影，
不是可用业务能力；浏览器默认空白窗口外观不建立 BrowserSession，文件统计不伪造数据。
按访问保留轻量页面的滚动/折叠状态，隐藏页暂停 ticker 并排除焦点，不产生 I/O；首页 pager 和 AI
草稿在页面往返时继续保留。设置入口不打开开发诊断。

AI左抽屉仍由HomeShell管理；工作流目录和抽屉计数共享WorkflowController的不可变投影。
AI顶栏浏览器/文件入口由app接到既有一级目的地，返回保留原pager与草稿；默认角色
头像按稳定ID复用品牌资源。历史手势说明的隐藏事实保存在同一Rust偏好JSON，旧记录
缺少`show_swipe_hint`时默认显示，不新建存储或改变schema版本。
聊天历史与角色选择的面板/遮罩局限于状态栏和64px顶栏下方；与全高AI主导航抽屉不同。
历史入口的数量表示同一ChatController内仍活跃且已获得Run的会话数；至少两项显示胶囊，
不使用历史目录数量。CLASSIC附件在输入行下方内联展开，AGENT仍使用右下弹卡；两者共享
动作与草稿身份。记忆选择器由常驻宿主持有，面板收起后仍可返回选择，切会话时结果失效。
KiyoriScrollBehavior统一保留滚动时子控件首击，手势识别与停止运动仍由框架持有。
持久化权威为既有Rust Runtime管理的SQLite，Application Support目录由app通过
path_provider提供；Dart不维护第二存储。短事务提交后即为业务事实，页面退出仅抑制迟到
回填；runtime关闭等待当前事务并释放连接，后续操作拒绝。schema更高/损坏时拒绝覆盖。
定义创建/编辑/启用/删除不等于WorkflowRun执行，节点、工具与调度按后续切片接入。
契约见[SQLite决策](../decisions/0005-runtime-sqlite-storage.md)。

## 知识、日记与图谱

记忆空间、逻辑目录、手工记忆和知识笔记复用同一Runtime/SQLite，schema2在原迁移事务
增加表而保留工作流。默认空间不能删除；空间级删除与活跃空间回退同一事务。目录删除
保留正文移到根，重命名同步后代；路径不映射宿主文件系统。Rust按空间/类型/条件分页
检索，每页100条400字符摘要，详情按space+id读完整正文，摘要不能用于覆盖全文。
日记阶段、完结状态与摘要由Rust从正文推导，不新增平行状态列；追加在Immediate事务内
读取最新正文，归档后拒绝追加。单节最多20000个UTF-16单元，时间保存为本地日期文本。
末节closed代表完结，后续追加重新进行中；全文编辑可改写历史，界面明确提示。列表状态
先于分页过滤，日期分组仅针对已加载页。schema3关系表属于同一空间存储，删除端点级联；
有向关系按来源/目标/类型去重，拒绝自环与非有限权重。图谱使用同读事务的当前结果前200项，
只包含两端都在该范围内的边。坐标、缩放与框选属于Dart投影，描述与权重归Rust事实。
schema4保存空间检索权重、自动记录间隔/规则和图谱偏好；图谱独立写入避免过期草稿覆盖。
本地模拟搜索逐条完整扫描正文并返回最多100项分数解释，Jieba搜索词法/RRF与关系传播归Rust。
普通列表暂仍字面查询；模拟未接AI召回。自动提取执行、云嵌入凭据、文档导入和向量索引尚未实现。

## 设置路由与展示边界

设置详情由 app 装配并使用 Navigator 页面栈返回准确来源，模态路由先消费 Back。
`SettingsNavigation` 仅聚合详情构造与回调，不持有导航选中项、页面缓存或业务状态；
`HomeShell` 仍是一级导航唯一所有者。新增详情接线不应继续扩张 Shell 的手势实现文件。
共享设置组件不持有领域数据；浏览器/下载/文件/视频设置目前主要显示源码默认态，保存与
系统动作空点击。主页模式、文字比例、输入草稿是局部预览，不代表真实配置已生效。
工具箱由`ToolboxSettingsPresentation`投影稳定工具/分组ID、加载、保存和错误；页面
`ToolboxSettingsSession`只拥有模态路由，目录移除释放实体弹层，保存中统一禁止退出。
名称和筛选是输入预览，不写布局、颜色、插件或工具执行事实；NFKC规则见
[Unicode输入校验决策](../decisions/0004-unicode-input-normalization.md)。
一级设置、收缩详情和工作台复用 `SettingsTheme` / `PrimaryPalette` 的旧明暗色表；
`IconTone` 按宿主明暗选择旧角色图标色。初始颜色草稿可保留固定值，渲染不能据此锁定浅色。
此投影不接管主题偏好；产品入口仍为当前浅色预览，暗色通过注入宿主主题验证。
更多功能中的存储与代理采用相同边界：旧 Android 默认路径只是文字快照，不映射到
当前宿主目录；输入外观校验不会授权文件或网络访问。产物编辑离开确认只处理草稿。
权限页只投影注入快照，默认未知，不读系统权限；协议页是旧完整正文阅读，不保存同意事实。
引导的模态宿主隔离底层设置，法律阅读先消费返回；每次重看从第一页开始。协议预览通过
后才加入第六页，阅读状态与权限选择只在该宿主生存，退出即释放，不成为业务授权来源。
聊天历史管理从 ChatHistoryPresentation 投影统计、角色/群聊与工作区；筛选、选择和日期
属于局部草稿，离屏保留，离开页面释放。归类、重建、删除均无业务副作用；默认空快照
不代表已扫描数据库。日期输入使用 SDK 中文本地化，仅作用于该弹层，不改变应用语言。

## 模型配置、凭据与请求

上下文与总结通过Runtime读取chat功能绑定，模型参数仅更新该配置的上下文/总结字段。
历史媒体保留为全局history_retention事实，不随模型复制；同一事务校验绑定和两者revision。
700ms去抖与返回前刷写，失败留草稿；媒体重置不改变模型revision。纯快照测试不持久写入。
功能模型分配由 PersistentModelsPage / ModelsController 接入同一 Rust 模型目录，按稳定配置 ID
与模型名保存 11 项功能绑定，并支持事务恢复默认。纯 FunctionModelsPage 仍可接收测试快照；
能力警告来自真实目录，未知不等于不支持，分配页测试按钮尚未接入，不伪造连接结果。
模型与API目录现投影Rust schema18，同一目录供功能分配、角色选择和独立上下文页。
配置ID+模型名为稳定引用，重排不换绑，删除有引用模型须显式替代，角色关联推进revision。
页面700ms去抖和离开前刷写串行保存；错误留草稿，成功后刷新失败不重复提交。
密钥/key池/headers由kiyori_platform安全存储保护，SQLite只有不可变reference；
普通参数与端点不属于加密数据。供应商端点仍是旧默认值；模型测试使用core/chat执行真实
Chat/Responses/Messages/Gemini网络请求，Runtime单client、无重试/重定向、直接连接、固定Mozilla根。
Messages按提供方采用x-api-key或Bearer，Gemini默认models根派生实际生成路径且密钥只放头部。
本地模型目录由core/local_models读取，同HTTP client与SQLite保存最后成功目录。
core/downloads唯一持有前台Transfer，core/files持有应用私有ResourceRef；冻结revision/
大小/SHA256，OS锁单执行者，Range/实体/全文件校验后原子交付。页面离开暂停其前台任务，
重开对账不自动重发；尚无OS后台移交。见[ADR 0009](../decisions/0009-managed-model-transfers.md)。
MNN/llama.cpp CPU文字推理由platform/native adapter拥有每请求C++句柄，core仍拥有ChatRun/
SQLite/总结与配置队列。资源来自completed Transfer，同OS锁覆盖加载至析构；取消等待worker
资源释放后终态。GGUF选择器只借用单次文件句柄，1 MiB分片进入Rust暂存、SHA256/头部检查、
原子交付同Transfer，不接受绝对路径；完整模型格式在引擎加载时校验。未完成导入清理后需重新选择。
GPU、媒体、原生工具模板、llama思考及扩展提供方未接入时明确失败。MNN固定引擎不支持的
seed/负惩罚/repetition<1明确拒绝。见[ADR 0010](../decisions/0010-native-model-inference.md)。
8事件队列背压、单事件1 MiB；Chat需finish与DONE，Responses需completed/incomplete终态及快照一致性。
Responses使用input、store=false/background=false，max_tokens映射输出限制；思考不混入正文。
请求取消等待worker释放，
错误不回显凭据/URL/正文；模型探测按配置和执行代次隔离。
原生/XML工具探测只执行schema严格匹配的本地echo和随机结果续答，不授予实际系统工具权限；
媒体使用固定旧素材，按协议/开关编码，结果分为通过、未验证和失败，实际用户附件另行接入。
模型目录由同HTTP client分页获取，整次60秒/8 MiB/20000项/100页有界且不发布截断结果；
配置目录和工具续答共用持久密钥游标，Dart无第二凭据选择器。目录只派生当前主机上的路径。
Runtime的配置级RPM/并发门控按单调时钟计数；保存新限制唤醒旧等待者，取消释放等待及在途槽。
保存成功后的门控更新只使用已提交revision和值，迟到更新不覆盖新限制；不再做可能误报
保存失败的第二次读取。Sol6.1自动思考五档映射，关闭明确拒绝；显式参数优先。
契约与依赖见[ADR 0007](../decisions/0007-chat-request-runtime.md)。
pending/active/retired状态由跨进程lease保护恢复；安全payload v3保存密钥池稳定ID、启用状态及
可用性，兼容v1字符串列表/v2无标记条目。旧二进制不支持v3，不能直接降级读取。
core/chat/pool拥有enabled+UNTESTED筛选、5并发探测和结果判定；UI逐ID加密保存结果。
暂停等待worker与在途保存；输入改变使旧执行代次失效，取消不标不可用。已保存标记属于测试时
快照，变更端点/模型后由用户清标记重测。core/model_execution读取已保存配置revision，
按启用项/可用性选择候选并原子推进独立游标；游标不改变配置revision，删除配置级联清除。
无标记且无启用项时才可回退单密钥；已有标记却无AVAILABLE明确失败。RANDOM使用安全随机采样。
模型测试与正式会话均消费真实轮换；正式会话短lease覆盖当前配置解析、native读取和请求冻结，
见[ADR 0006](../decisions/0006-model-secrets-and-configurations.md)。

## 会话、总结与请求观测

core/conversations拥有会话、消息和Run，复用同一Runtime/SQLite；ChatController只持有草稿、
订阅及快照。会话绑定角色ID，发送时解析该角色当前提示词/固定模型，否则使用chat功能绑定。
每会话OS锁保护单个执行；跨实例读取只恢复无锁的running为interrupted，绝不自动重放。
先事务保存用户消息和Run，再执行网络；文本先持久化后投影，取消/失败保留已有正文。
每次请求只交付一个终态；切换会话保留原执行归属，显式停止与桌面退出等待保存。
消息编辑重发在配置/凭据校验后同事务替换尾部历史。单条助手重新生成保留后续消息，
旧回复保存在同库版本表，可切换；发送使用当前选中的版本。schema15回滚须恢复升级前一致数据，
不能修改user_version。详细生命周期与验证边界见[请求契约](../decisions/0007-chat-request-runtime.md)。
core/conversations_summary在同一Run的网络前阶段执行总结功能绑定，冻结独立配置、凭据与
聊天偏好；同worker取消覆盖总结与后续聊天，不在SQLite事务或安全lease内等待网络。
摘要缓存保存覆盖position与正文，仅作为下一次请求投影，原始消息及搜索结果保持完整。
计数从上次覆盖边界之后的user消息派生；估算比例与保守字节比例都可触发，预算超限明确失败。
完成后复核绑定/配置/角色/偏好和running事实，迟到摘要拒绝写入；消息编辑/删除/版本切换、
重发覆盖边界或清空会话使缓存失效，分支只复制其前缀以内缓存。关闭总结忽略缓存，重新开启
可继承有效缓存。总结用量独立保存并计入累计，最近聊天样本不被总结usage覆盖。
schema15与取舍见[摘要投影决策](../decisions/0008-conversation-summary-projection.md)。
手动插入总结使用同SUMMARY绑定/短lease/ChatRun，会话OS锁内冻结边界、原文和路由；
用户边界不含该user、AI边界含该回复，完整成功后才原子插入summary条，原文保留。
后续请求从有效手动检查点继续，协议投影为user；编辑较早原文使后续检查点失效但全文
可见，编辑/删除摘要和分支沿同库事务。schema18的Run.kind区分手动摘要与聊天累计和
最近样本；取消/失败无半条摘要，Dart不建立第二执行owner。详见同一摘要决策。
供应商缓存读写及推理细分属于同一次Run，重复usage替换而不累加；未提供保持NULL。
累计排除运行中的请求；有效缓存输入作为命中率分母，异常缓存不影响输入/输出总数。
可选usage格式异常只跳过观察，不中断有效回复；仅输入样本不进入完整用量累计。
Runtime按会话持有最新请求观测，core/chat/observation用单调时钟及实际出站消息估算；
最近样本/速度不从SQLite恢复，取消/失败清除、删除/关闭释放，旧执行无法覆盖新tracker。
非流式、单分片、未报告最终输出均不发布完成速度。UI只投影核心观测，顶栏不按分片刷新。
密钥池的TextExchange只处理单次用户选择的文本，不暴露路径给feature或建立文件库。
导入UTF-8逐行追加，空行忽略、重复值保留；原文件和合并payload上限1 MiB，超限不改草稿。
Windows COM不添加最近文档，Android SAF不持久授权/缓存；导出为用户选择位置的明文文件。
取消不变更；flush等待未完选择，宿主移除抑制迟到回填。iOS当前明确unsupported。
模型配置缓存的直接子节点按配置 ID 标识，重排保留同一实体草稿，删除释放，重新加入不
复活已释放草稿。异步选择返回后按当前目录解析 ID，不能用弹层打开时的索引写回。

## 角色、标签与群组

角色卡/提示词目录由PromptsController从同一Runtime/SQLite schema5投影；
默认Kiyori的中文初始化归Rust，纯快照测试仍可注入旧外观。八字段、标签、模型/记忆/
工具绑定先持有草稿；嵌套保存只回填父层，最终保存/创建/复制/删除/激活写入Rust事实。
写入校验revision并原子验证引用，失败保留草稿；取消或Back在未保存时直接丢弃草稿。
菜单和弹层固定稳定 ID 与本次存在代次；重排保留，删除关闭整个编辑会话，同 ID 重入
不复活旧草稿。群组默认空态，也可投影注入列表、活跃徽章和按 ID 隔离的名称/描述/成员
草稿。成员选择保留旧下拉后添加、尾部追加/移除顺序；不存在群组规划参数或默认群组。
角色与群组活跃徽章互斥；默认不能删除，删除活跃目标回默认，关联清理推进revision。
模型目录及单角色基本文字执行已经接入；头像主题克隆、历史批量关联和导入导出尚未实现，详见
[角色卡契约](../design/character-prompts.md)。
标签批量导出默认全选本次目录，按存在代次清除失效项，导入/导出中外观来自快照。
标签市场保留旧13项中文预设，HTML与链接仅为文本；添加通过同一owner保存全文。人设生成复用
同一角色目录与八字段结构，按访问创建controller，切换保留、实体移除释放；消息与生成
状态来自PersonaPresentation，侧栏选择不写真实活跃角色，发送/工具/存储尚未接入。

## 尚未接入的 AI 展示能力

AI 工具授权从只读目录与授权快照生成草稿，例外选择只在页面内互斥，不授予工具执行权限；
默认空目录不代表平台已完成工具注册。用户资料的 Markdown 与旧档案由快照提供，草稿和
选区仅随页面存活；保存、复制及文件迁移尚未接入，不建立 Dart 文件仓储。12000 字符限制
只控制保存外观，超限原文不截断。基础预览复用标准 Markdown AST，按旧样式绘制，详见
[资料预览决策](../decisions/0003-profile-markdown-presentation.md)。
局域网与自动化严格区分端口/Token输入草稿与已注入服务快照；输入不改变地址和调用示例，
开关不伪造运行状态，不监听端口或注册广播。HTTP/Intent示例是旧Android协议的阅读外观。
回复与表情持有单页参数草稿，不改变角色或消息发送策略。表情库展示打包原素材或注入图片，
按三列惰性构建并按格子尺寸解码；不扫描宿主文件，不复制到用户数据目录或建立图片仓储。
AI用量页接收领域计算后的CNY统计与模型价格，不建立Dart计费引擎或静态价格数据库。
模型排序与图表只投影快照；汇率输入不会改变显示总费用，重置/保存不写统计或定价。
语音配置目录由快照注入；STT 的引擎、端点、密钥与模型草稿按配置 ID 隔离，移除配置或
关闭页面释放输入控制器。切换引擎不替换远程草稿，不录音、不初始化语音引擎或自动保存。
TTS 复用语音配置目录，保留旧首次 Next HTTP 展示预设；远程地址仅为文本。
豆包引擎切换按旧 UI 更新端点/音色/Content-Type 草稿；其它引擎共用本配置远程草稿。
系统音色与远程模型目录由快照注入，不用 provider 常量伪装已获取目录。清理规则只编辑
文本，不执行正则；HTTP/VITS JSON 校验只控制错误外观，不解析或执行业务响应管线。
语音唤醒的监听、模板数量和录音进度属于外部快照，按钮不能更改这些事实；识别方式、
文字和自动附加开关属于短暂预览。附件编辑弹窗不会保存、删除或抓取设备上下文。

## 账号、代理与音乐展示

账号页由AccountPresentation投影连接、读取、失效和错误，确认退出/移除不改写账号事实；
Cookie只随登录弹层存活。形象页由AvatarPresentation提供目录，模型参数/情绪绑定为
按实体存在代次隔离的草稿；删除后重入不复活旧值。模型及自定义类型编辑弹层归页面
会话，卸载时释放；不创建renderer、不轮询动画、不导入或写文件。预览无adapter时使用
旧“不支持的模型类型”分支。公共CompactExpandField只统一角色/群组的同源几何。

GitHub登录内嵌壳投影加载/完成/错误，未建立OAuth或WebView；B站已生成挑战和图像由
宿主注入，切换方式清除本地展示引用，不请求二维码或改变账号。广告拦截快照不拥有
规则引擎；目录搜索/展开与编辑草稿属于UI，删除实体或宿主时精确释放所属模态。

网络代理由NetworkProxyPresentation投影配置可读性、运行阶段、外部路由、订阅/策略组/
节点、规则、脚本和脱敏日志。节点搜索/排序、规则输入和日志筛选属于页面草稿；点击不改变
运行、测速或选中事实。订阅与规则按ID存在期管理弹层，当前订阅规则变化或切换时释放旧
草稿，忙碌快照同步更新已打开弹层。日志保持领域插入顺序的逆序，不按可能回退的时钟排序。
真实配置、Mihomo、系统网络、文件和凭据仍由后续Rust/native owner接入。

音乐设置由MusicSettingsPresentation提供音源摘要、偏好、播放器、备份解析结果与操作状态；
不包含脚本正文、文件读取或MusicWorkspace副本。音源链接只随模态存活，默认遮蔽；
移除实体释放详情/编辑/确认，重排保留输入。备份预览按解析结果ID隔离，取消不因列表
离屏重入重新打开；页面退出释放全部局部会话。下载路径复用共享下载owner的摘要，
音乐/桌面歌词按钮不改变系统事实，滑块只在拖动中显示草稿，释放后返回快照值。



## 历史、消息与审计

对话历史由Runtime/SQLite拥有目录、活跃会话、绑定、分组与顺序。删除当前会话时先在
同事务选择同绑定最新项，无候选则创建；单项删除继承分组，整组删除不继承。分组命令
冻结作用域和成员revision，锁定或执行中的任一成员拒绝整组删除。UI折叠状态随聊天
宿主保留；实体弹层只释放自己的路由和确认，不误关历史目录或底层页面。
历史元数据绑定菜单由编辑会话持有，与只读字段同宽并锚定展开；Back/遮罩先收菜单，
选择只修改草稿，保存才写同Runtime。ChatController目录变更刷新选项与名称而保留标题，
移除的绑定不成为伪选项；会话删除时菜单随所属编辑框释放。菜单在真实键盘/安全区内
保留上下48dp，按下方、上方、顶端居中、窗口边缘候选定位，圆角12；开合沿旧普通
主题弹簧保留反向速度，关闭结束释放帧。历史弹窗使用surfaceContainerHigh、20圆角，
固定标题与操作，只滚动正文。新建分组纯空白直接退出；重命名trim等值直接关闭不写库。
新建分组打开时冻结绑定，按文件夹模式不绑定角色；提交时冻结当前会话ID，通过
history_group内部JSON的selection.origin在同Immediate事务比较最新active，迟到创建
只保存分组而不夺回其它入口选择。旧请求未提供selection仍保持原自动选择语义。
提交后读取失败进入已创建的关闭状态，输入禁用且不能重复创建；提交前失败保留可重试
草稿。ChatController刷新拒绝过期回填；Android选择变化提示复用系统长Toast，原生
宿主释放时取消，桌面与适配器不可用时使用现有短暂消息，不伪造系统提示成功。
历史“新建对话”继承数据库当前会话的分组；空绑定参数回落当前单角色，当前群聊只有
显式群聊ID才绑定，沿旧delegate的实际语义。空会话标题保存本地“新对话 H:mm:ss”，
分组创建、删空替代与普通创建复用同函数；首轮有效user按旧行为先设“新对话”回退，
独立titleGeneration非流式、无自动重试，完成后用标题版本和源消息CAS更新。
history_create返回成功表示创建已提交，随后刷新失败仍显示error并收起原入口，避免
重复创建；异步完成只移除捕获的历史路由，不关闭后来打开的窗口。
当前无user的单角色会话按旧绑定优先同步开场白，群聊/真实模型回复不替换；更新保留
消息身份与创建时间。schema23消息元数据属于同SQLite，created_at不冒充sent_at；
已有消息缺时间保持未知。同步审计与消息同事务，幂等不推进revision，分支复制独立
元数据；有user后冻结开场白。桥created_at由正式生成入口更新，详见ADR0017。
schema24的conversation_title_requests保存辅助执行、真实用量和终态，不占聊天Run。
标题与聊天复用同client、凭据租约、配额、native adapter及请求审计；短租约释放后
开放下一轮，标题网络独立继续。失败/取消/中断保持回退，删会话取消所属请求；改名
及源消息编辑使迟到标题失效，标题更新updated_at但不推进消息revision。用量不混入
聊天统计；全局provider累计页面与真实文件附件尚未接入。迁移/恢复见ADR0018。
当前默认角色作用域包含未绑定历史，按角色分类时两者分桶；列表、菜单和拖排使用
同一排序边界。分组JSON的include_unbound默认false，只允许默认角色显式开启；
打开弹层时冻结绑定、该标志及成员revision，切换模式不改变已确认的操作范围。
拖排只持有本次目录/几何草稿，合法中点让位才反馈，松手一次事务；取消、搜索、外部
目录变化或宿主退出不写库。空/折叠桶按头部解析归属，无可见锚点时从完整目录表达
原相对位置，不能把隐藏成员当空桶。Android移动触觉为TEXT_HANDLE_MOVE，遵守系统设置。
历史搜索在query/目录记录值变化后400ms查询同Runtime，等值重读及无关通知不重启。
详情时间线全文搜索独立使用350ms防抖；Rust每批扫描100条未过滤事件，返回实际扫描量、
最后扫描序号游标及命中摘录。多词字面AND可跨已记录元数据/正文；单字符大小写兼容旧
Kotlin，ß不扩为SS。UI续扫至本次新增至少100命中或到尾，再由“继续搜索”推进；中途
失败保留命中与游标，切词/标签立即使旧请求失效。原始事件仍只搜已加载元数据。各
标签保留查询和滚动，离开时间线释放搜索结果/游标，返回按保留查询重新搜索；trim后
等值查询不重启。基础详情加载独立于搜索和标签生命周期；搜索不禁用备注/导出，模态
关闭只刷新基础事实。基础加载失败始终显示独立重试，不被搜索结果遮蔽；重试不推进
全文搜索。备注取消保留详情宿主草稿，成功才清空。展开集随离开标签释放。
时间线初次打开和底部跟随按布局结果校准到实际末端，避免惰性列表估算距离留下不可见的新事件。
上翻阅读时保留位置，通过“新事件”入口主动到尾；指针、滚轮、搜索、切标签、加载更早事件和
宿主销毁撤销尚未完成的校准，抵达末端后不继续申请帧。
对话标签使用完整trim词分别匹配各字段，不拼接字段制造跨边界命中。未知Provider/工具事实
不重建；搜索不改schema、签名或事件链。
即时标题/分组沿Kotlin单字符忽略大小写映射，与异步正文结果取并集；正文门槛为两个
UTF-16单元，SQLite大小写及字面%/_语义保留，清空/改词拒绝迟到回填。
schema20增加父引用与基础审计链。迁移前修订/供应商原始事件未知，BASIC快照不冒充
完整审计。备注只追加审计，消息编辑保留原文与修订。详情页摘要100条、正文8192字符
分页；超限导出失败并保留原文。原始kiyori-audit-v1链继续保存，产品导出采用下述
旧schema1移植合同；签名不证明作者身份，基础契约见[ADR 0014](../decisions/0014-conversation-history-and-audit.md)。
schema21由同AppStore保存大小/Run元数据和持久封印，native端口保护审计payload；
Android Keystore与Windows DPAPI密钥失败不回退明文，公钥和已有密文在重开时核对。
产品签名使用P-256，参考Rust测试构造器不用于产品安全存储且拒绝打开已保护库。
正文保护不等于会话原文或全库加密，见[ADR0015](../decisions/0015-audit-native-protection.md)。
产品导出改为旧schema1的BASIC移植投影、九类文件与去重payload，链头ASCII持久P256封印；
原始八字段链继续保留，旧messageTimestamp仅是首次审计观察定位符，不代表发送时间。
诊断64KiB/8MiB预算、重复引用和私有路径假名化见[ADR0016](../decisions/0016-portable-audit-export.md)。

## 主题、备份与运行检查

主题设置五面板只持有展示草稿；聊天样式编辑器与预览共享同一面板状态。切换标签保留
草稿，切换聊天风格不丢字体/图片参数；不写全局主题或角色配置。
字体快照只引用宿主已注册family和展示文件名，UI不加载字体路径；头像借用已解码资源。
角色与全局头像选择器独立，聊天样例才在角色头像为空时使用全局头像；预览固定圆形。
已选背景/气泡媒体通过AppearanceMediaPresentation借用稳定ID与已解码图像；UI只释放自身
九宫格切片，不释放资源owner句柄。相同参数重建快照保留草稿，媒体移除或权威参数改变
重置对应草稿。视频预览仅投影传入帧，静音/循环是局部预览，不构建播放器或伪造播放。
界面定制父级的语言、全局显示和布局调整同样只持有展示草稿；数值范围与条件项复刻旧
默认态，但不写 locale、偏好、通知、后台服务、Root 或截图事实。

备份页面用BackupPresentation投影独立操作阶段、统计、已解析备份与提示会话；Dart不扫描
路径、不导入导出、不恢复或重启。页面拥有模态路由，导出选择沿两层会话存活并按当前
目录取交集；记忆配置移除释放策略层，同ID重入不恢复旧选择。导入文件和操作完成提示
由稳定会话ID注入，取消后同一提示不因列表回收重开。最近备份仅展示领域提供的前三份。

M1 运行时由 Rust `Runtime` 拥有；`RuntimeHandle`/`TaskHandle` 是 FFI 句柄。`NativeRuntimeClient` 提供 Dart 外观，按需拉取任务事件并投影为单订阅 Stream。诊断任务不是助手/下载任务，不保存用户数据。关闭会话取消其任务，取消订阅释放任务句柄；不可用产品能力返回 `not_implemented`，不伪装为可用。
