“像素完全一致”。iOS 源码适配不代替 Apple 构建。

## 架构与性能

`app/shell` 装配 feature，一级目的地继续由 HomeShell 持有；详情导航交给 Flutter
Navigator 的页面栈，保留原来源页。模态路由拥有自己的返回，避免 Shell 抢先退到首页。
feature 只接受类型化回调，禁止反向依赖 app。共享几何与无业务 UI 组件放 kiyori_ui，
各 feature 页面各自保存短暂草稿/搜索/选中状态，不建立统一巨型页面目录或业务路由旁路。

UI-only 阶段配置操作保持空点击；选择器可浏览、返回和编辑局部草稿，保存不写持久层。
系统动作、下载、网络、WebView、扫描、模型和外部账号均不启动。后续 Rust 负责领域事实，
原生 adapter 拥有真实句柄，Dart 复用当前 UI 接入快照和命令。

高频滚动仅更新标题子树；长列表用惰性构建；页面访问才创建；隐藏页暂停 ticker；dispose
释放 controller。Android 对齐旧尺寸，桌面考虑窗口收窄、鼠标、键盘与焦点，iOS 只用
平台 inset、通用布局与导航。不能用性能优化为由截断正文或改变默认几何。

## 验证、恢复与授权

每批先相关 widget 检查，再 `tools/verify.ps1`；公共组件影响多个入口时回归已有页。
UI 批次按 [验证策略](../development/testing.md) 构建 Android/Windows，截图在忽略的
work 目录，设备 Profile 证据另记。源代码/文档通过补丁修改，旧仓库只读；提交、推送、
安装、远端和发布依据当前任务分别授权，历史授权不延伸到新任务。
回滚点为开始时核对的 HEAD，保留任务前已有改动，禁止广泛清理。

正式 Goal 追踪当前已授权范围；当前任务与自动化状态仅见[实施状态](../status.md)。
设计方案不授权启动或恢复调度。暂停或终止后保留已写入结果与未验证清单。
