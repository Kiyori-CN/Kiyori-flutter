## 几何与交互

工作台复用 `SettingsWorkspacePage` 与 `SettingsTheme`。三标签外边距12×8、圆角12、
描边1、内部4、最小行高42，按钮圆角8；大字体允许增长。正文外边距12、项间8；
角色卡圆角8/描边0.5/内边距12、头像40、头像与标题间距10，菜单图标20。
预览按旧源显示40字与省略标记，完整编辑正文保留，不截断控制器文本。

角色编辑器宽度95%、内边距16、头像48/描边1.5；字段字号12、标签/提示11、圆角6、
展开按钮40/图标14。头部与正文间12，常规正文最大320高；短屏、双倍字号或键盘压缩
时整个正文滚动，底部取消/保存保持可达。浮动标签上方保留绘制空间，头像操作使用
Material Add/Refresh 图标，不用字体符号替代。大屏编辑外边距8/内边距16、正文填满
剩余空间，确认回填、取消/关闭/Back 丢弃本层修改。桌面遵循已有840最大内容宽。

模型与记忆选择使用旧6px行圆角、紧凑文字、选中色块/勾选、细描边与模型二级展开；
模型选择以配置 ID 和模型名回填，重新读取目录时不使用旧位置索引。记忆使用稳定 ID。
默认目录为空；固定绑定开关只改变草稿，不产生配置。工具弹层四分类、搜索、选择、
取消与确认遵循旧层级；允许外部包/Skill/MCP而缺少 `use_package` 时保留明确校验。
此校验只表现原表单错误，不是权限裁决或工具执行器。

标签编辑保留名称/可选描述/提示词三字段，提示词4–12行；删除确认按 ID 定位。
导出模式保留 JSON、PNG、多维码三张直接操作卡；多维码颜色选项为2/4/8/16、默认8。
JSON/PNG不写文件，多维码不生成假图或假加载状态。原导出路径是阅读文案快照，不映射
到新应用目录，也不授权访问旧应用数据。真实导出接入前必须用新资源/存储策略替换路径。

## 状态与生命周期

`PromptsPresentation` 是只读目录输入，默认卡只是旧初始化外观快照；`activeCardId`
徽章由输入决定。页面缓存排序结果，只在目录或排序选择变化时计算，列表按需构建。
`CharacterCardEditor` 的控制器、标签选择和绑定草稿仅存活于一个实体编辑弹层；关闭
后释放，重新打开读取输入快照。新建草稿不生成数据库 ID、不向目录插入记录。

主列表直接实体节点使用稳定 Key，并向惰性列表提供新索引映射，保证重排不会销毁已
打开菜单的宿主。菜单固定实体 ID 与本次目录代次；选择后重新解析当前目录。删除后
重新加入同 ID 产生新代次，旧菜单/编辑会话不能操作新实体。

`PromptDialog` 仅跟踪本次会话创建的模态路由。目录移除实体时精确关闭本弹层及嵌套
弹层；宿主卸载时也清理，不能广泛 pop 误退其它页面。跨路由快照在帧结束后通知，避免
构建阶段请求另一个路由 rebuild。异步选择返回同时检查 mounted、会话有效性和当前 ID。
模式选择、文本输入、筛选均无网络任务、订阅服务或后台 ticker；TextField 释放焦点和
控制器，Navigator 负责模态前后台隔离。工具目录移除的选项在回填时过滤。

## 后续领域接入条件

新增真实角色/标签/群组服务时由 Rust 保存唯一事实，app 注入快照与类型化命令；不能
在这些 Dart 页面补数据库或模拟成功。写入必须考虑 revision 冲突、取消/超时、删除
期间的回调失效、关联标签/群组/模型/记忆/会话清理，以及成功后快照回流再关闭编辑器。
头像与导出使用共享 ResourceRef 和系统授权。原生形象句柄由 adapter 管生命周期。
默认数据迁移和双语语言切换必须由真实配置 owner 决定，不把 Dart 常量当持久数据。

真机同设备明暗/字形/阴影/触摸/Profile/TalkBack，以及 iOS Apple 构建仍为独立验收。
本机 widget 截图和 Windows 引擎只证明对应层，不宣称 Android 像素一致或性能达标。
