# 文档、知识、工作流与辅助领域

这些是旧项目审查后补齐的**设计契约**，工作流定义存储已开始实施，其余按切片推进。源码地图见
[旧模块地图](../architecture/legacy-module-map.md)，进度只在 [status](../status.md) 维护。

## 文档工作台

`documents` 拥有打开文档、格式、revision、草稿、保存事务与阅读位置；资源读取仍经 files。
前台单个编辑/渲染引擎，后台文档保留快照而非无限引擎实例。文本、代码、TXT/EPUB、PDF、
Word、表格和演示文稿共用入口与资源身份，内容模型和格式能力分别定义。

大文档分段解析/布局，正文完整保留；文本位置用字符/语义锚点与 revision，像素仅作为
当前布局投影。阅读设置变化需重算测量后的整行页界；两端对齐、零段距、翻页裁切和
Word fit-width 横向锁定各有回归，不靠删除尾部内容或固定假行高解决。

保存先冻结文档身份/revision，再执行可取消准备；提交阶段结果未知必须保留恢复状态，
关闭窗口不能把不确定保存当成功。Office/代码编辑器/原生纹理选型先做平台与许可证 spike；
滚动 chrome 只改变绘制或有限布局，不让每一像素动画触发全文重排。

## 记忆、日记和知识

`knowledge` 的单一仓储在 workspace/角色空间内保存内容、目录、标签、关系、归档与来源；
记忆/日记/知识是内容类型，不是三套数据库。稳定 ID 进入工具，显示标题不能充当唯一身份。
文档区块带来源 revision，引用必须能追溯完整原文。图谱是有界视图，不加载全库绘制。

向量是派生索引，身份含规范化 provider/模型、内容指纹、维度和索引版本。不同模型即使
维度相同也不混查；内容变更使旧向量失效。删除/归档与派生索引对账，后台嵌入必须有
明确授权与取消，外部材料不能变成权限。导入旧 ObjectBox/JSON 先经过版本化迁移包，
新应用不直接操作旧库。

## 工作流

`workflows` 保存定义与不可变运行快照，节点调用统一 tools/permissions。编辑运行中的
定义不改变已启动 run。校验依赖、环、输入 schema 与能力后执行；并发有界。
节点终态区分成功、失败、跳过、取消和外部结果未知；取消传播至工具，运行日志只存脱敏
摘要。恢复不能重复执行已经提交且结果未知的写操作，重试需由节点幂等契约决定。

先实现顺序两个节点与取消/失败恢复，再建立复杂可视编辑器、计划/触发器。调度器依赖
持久化和 OS 后台能力，不能靠页面 Timer 保证应用退出后继续执行。

## 账号、内容与语音

- accounts 保存验证后的产品账号投影和凭据引用；provider 模型凭据与产品账号分域。
  B站扫码/浏览器导入不创建第二 WebView、不外发 Cookie 给脚本，登录结果绑定账号身份。
- content/bilibili 与天气等内容 adapter 只查询/规范化结果；播放交给 media，下载交给
  downloads。推荐、热门、番剧、影视和我的沿用旧交互；API 失效清楚失败，不伪造列表。
- speech 管 STT/TTS 配置租约、麦克风、音频资源和停止；配置切换先摘除旧实例再释放，
  失败不能重新交出已关闭实例。流式音频有背压，权限撤销即停录，录音不因页面预热启动。
- avatar 只管理角色资源和展示会话，动画离屏暂停，贴图/模型释放可测；各格式的平台支持
  与许可分别确认。复杂渲染放原生纹理端口，不把每帧模型数据经 DTO 往返。

## 备份、审计与系统能力

backup 定义版本 manifest、内容校验、凭据排除、导入预览、事务恢复。audit 保存运行与
修订证据，diagnostics 保存可丢弃技术日志，两者保留周期不同，不复制私密消息到公共日志。
文件、导出包和备份使用同一资源服务；恢复验证完成前不能覆盖现用数据。

automation/integrations 处理 Android accessibility/屏幕捕获/虚拟显示、桌面进程和外部
Intent/HTTP/Tasker 入口。外部调用先认证并验证目标 workspace、调用来源与授权代次；
不能因 UI 自动化可用就默认授予任意文件/系统权限。Android Root/Shizuku、Windows 系统
权限、iOS 限制按平台返回能力原因。首次创建本地服务需 loopback、会话凭据和完整退出释放。

## 实施顺序与验收

资源/授权/存储是共同前置；文档先文本打开与可靠保存，知识先本地 CRUD/索引，工作流先
统一工具的两节点执行。账号/内容随媒体切片，语音/形象/系统自动化按能力独立推进。
每项必须同时验证错误、取消、旧结果回填、大数据和资源释放，并按
[性能契约](../development/performance.md)测量真实界面。保留原 UI 不等于复制旧框架。
