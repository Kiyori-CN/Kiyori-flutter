# ADR 0017：角色开场白与非生成消息事实

日期：2026-10-06。状态：已采用；实际验证见[status](../status.md)。

## 旧源与选择

来源为Kiyori-Android/6b03b03的ChatHistoryDelegate851–951、960–1058。
创建或选择单角色会话后，如果数据库没有任何user消息，同步第一条非模型assistant：
绑定角色卡优先，绑定失效回落当前单卡；绑定群聊跳过，当前群聊没有单卡回落。
开场白非空则添加或更新，空白则删除原非生成消息；真实模型回复始终保留。
更新保留消息身份和创建时间，有用户消息后不再同步历史开场白。

选择沿旧语义执行；创建、当前目录和快照读取复用同Runtime/SQLite Immediate事务。
同步不发生于Dart build，不新建模型Run、请求或用量。生成运行中拒绝同步；没有变化
不推进会话revision或更新时间。读取非当前会话只投影已保存历史，不同步其开场白。
消息增删改及其审计在同事务提交，审计失败回滚选择和消息；不吞错误或伪造成功。

## 元数据、桥与导出

schema23增加conversation_message_metadata子表，按message_id级联，保存非生成
消息的role_id、role_name和可空created_at。它仍属于同一AppStore，角色名称是消息
来源快照，不随当前角色名字直接变动。已有消息没有元数据时保留未知创建时间，
迁移不猜测或填入当前时间。Run消息沿原运行快照，模型发送时间sent_at继续独立。

桥在既有ConversationMessage追加可空created_at，由generate-bridge生成并Check；
详情timestamp使用真实创建时间，缺少时沿旧sent_at投影，不能将开场白计作供应商
请求。首次发送判断是否已有user，而不是总消息position为零；标题使用原用户输入，
引用标签只属于最终模型上下文。独立titleGeneration接入见[ADR0018](0018-independent-conversation-titles.md)。

新开场白的本机审计记录OPENING_SYNCHRONIZED及前后正文，基础记录明确已观察
快照。旧源链、旧密文和已保存签名不修改。导出副本保留非生成角色名称与真实创建
时间定位；未知旧消息继续使用已有移植定位规则。分支复制独立元数据，源会话删除
不影响分支。创建时间不作为模型发送时间或网络耗时来源。
同名同正文但角色ID改变时刷新来源，不改变消息身份/创建时间。无新createdAt的源事件
保持原portable投影说明字节，避免既有封印链头漂移；同时间冲突按原定位规则递增。

## 兼容、回滚与验收

schema22迁移保留消息、审计与封印，旧schema22程序不能读写schema23；程序回滚
需恢复升级前一致数据备份，不能删除元数据表后冒充无损降级。
没有新增依赖、网络请求或平台句柄。设备、供应商、发布和Apple验收授权没有扩大。

验证覆盖创建/选择/加载、幂等、绑定优先与失效回落、群聊、模型消息、空白删除、
用户消息后冻结、引用与首轮标题、分支、迁移未知时间、旧hash不变和审计失败回滚。
真实FFI/SQLite及明暗开场白渲染、完整verify与两端Debug按正式入口执行；设备像素、
TalkBack、触摸与Profile保持独立待验证。
