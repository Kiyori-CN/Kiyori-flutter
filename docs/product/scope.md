# 产品范围

本文定义长期产品范围与完成信号，不是已交付能力清单。当前可用入口见[使用指南](../user-guide/current-capabilities.md)，实际进度见[状态](../status.md)。

## 目标

Kiyori 是个人使用优先、本地数据优先的跨平台 AI 工作台。用户可以直接浏览、管理文件、下载、播放媒体，也可以授权 AI 调用这些相同能力。界面沿用旧 Kiyori 的 UI 与功能设计，按原有几何和交互适配手机与桌面；重构聚焦目录架构、可维护性及多平台实现，不另造一套产品视觉设计。

开发顺序为 Android 与 Windows 同级优先，iOS 同步纳入接口、资源模型、权限和测试设计。iOS 的真实编译与验收取决于 Apple 环境，不以 Windows 的模拟实现作为替代证据。

## 能力范围

| 领域 | 目标体验 | 首个可验收切片 |
| --- | --- | --- |
| AI 助手 | 会话、多模型接入、流式消息、工具调用、附件、可取消执行 | 一次流式问答和一次需授权的文件读取，取消后状态一致 |
| 扩展 | Script、Plugin、Skill、MCP 接入统一工具系统 | 一个无额外宿主权限的示例扩展及一个远程 MCP 连接 |
| 浏览器 | 多标签、历史、收藏、网页与 AI 协作 | 三端统一会话契约，Android/Windows 真实网页视图 |
| 工具箱 | 内置及扩展工具的可发现入口、参数编辑、结果展示 | 手动与 AI 调用同一工具，权限和结果一致 |
| 文件与下载 | 资源浏览、导入导出、下载队列、断点续传 | URI/路径两种资源，以及取消与恢复下载 |
| 视频与音乐 | 一份播放服务，分别提供视频视图和音乐库/队列 | 本地与网络媒体播放、队列、音频焦点和资源释放 |
| 广告拦截 | 规则订阅、应用内网页请求与页面规则、诊断 | 规则更新原子切换、站点豁免、可解释命中 |
| 网络代理 | 应用请求策略与平台支持的代理功能 | 应用内请求明确显示生效范围，不能代理的流量可诊断 |
| 终端 | 受权限约束的系统交互、进程输出与取消 | Windows 进程会话；Android/iOS 按能力边界实现 |
| 文档工作台 | 文本/代码/小说/PDF/Office 共用入口和资源身份 | 打开、编辑、可靠保存、完整原文与阅读位置 |
| 记忆与知识 | 记忆、日记、知识、关系与可追溯检索 | 空间隔离、CRUD/归档与派生索引失效 |
| 工作流 | 可取消、可审计的节点执行 | 两节点共用工具链，失败/恢复不重复副作用 |
| 账号与内容 | B站五栏、天气等旧内容入口 | 单账号所有者、内容查询、复用播放和下载 |
| 语音与形象 | STT/TTS、角色与悬浮表现 | 明确权限、配置租约与离屏资源释放 |
| 备份与系统集成 | 版本化导入导出、运行审计、平台允许的自动化 | 校验后恢复、来源认证、授权与可用性分离 |

## 当前不作为承诺

第一阶段不建设账号云、插件商店、远程设备控制、完整桌面浏览器扩展生态、跨端同步服务器或自研媒体解码器。不承诺 iOS 任意下载执行代码、无限后台运行、全盘访问或与桌面等价的终端。

业务能力按路线图逐项交付。UI 复刻阶段允许未接入按钮保持空点击，但不创建假业务实现或伪造成功结果；不迁移旧应用数据，不发布或上架。

## 质量目标

结构可读、边界可测试、任务可取消、错误可诊断、权限可撤销。性能数字在第一条真实路径建立后测量，记录设备、输入和基线；不在缺少原型时编造延迟、内存或跨平台复用比例。
